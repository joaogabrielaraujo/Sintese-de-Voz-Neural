<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Native picker → import controller | User-selected bytes and cancellation/errors cross an asynchronous platform boundary. |
| Audio completion → persisted progress | Native player events determine durable reading history. |
| UI delete action → local filesystem | A touch or keyboard command can permanently remove local data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-04-01 | Tampering | progress completion event | high | mitigate | Match stream generation and active item, handle once, persist completed separately from current. |
| T-14-04-02 | Denial of Service | re-entrant import | medium | mitigate | Dedicated single-flight flag spanning picker, parse, and persistence with finally reset. |
| T-14-04-03 | Repudiation | deletion | high | mitigate | Named confirmation, explicit destructive action, mutate UI only after repository success. |
| T-14-04-04 | Information Disclosure | storage error text | low | accept | Show actionable user-safe messages without exposing absolute private paths or raw payload data. |
</threat_model>
